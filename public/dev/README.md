# dev 전용 목 미디어 (홍보 영상 데모용)

이 폴더의 파일은 **개발 모드 "사장님 자동 로그인"** 상태에서만 사용됩니다.
프로덕션 동작과 무관하며, dev 데모에서 "영상이 생성되는 것처럼" 보이게 하기 위한 샘플입니다.

## 여기에 넣어주세요 (파일명 정확히 일치)

| 파일명 | 용도 | 권장 사양 |
|---|---|---|
| `promo-sample.mp4` | "영상 생성하기" 결과로 재생될 **영상** | 세로 9:16, mp4(H.264), 5~10초 |
| `promo-input.jpg` | 영상 생성 **입력 사진**(자동 세팅되어 생성 버튼이 바로 활성화됨) | jpg 또는 png, 음식/가게 사진 권장 |

> 파일명을 위와 다르게 두면 인식되지 않습니다. (png를 쓰면 `promo-input.png`로 두고 알려주세요)

넣으신 뒤 알려주시면, 파일 존재를 확인하고 dev 목이 이 파일들을 쓰도록 연결하겠습니다.
